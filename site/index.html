Quick start

curl https://API_HOST/v1/tts \
  -H "Authorization: Bearer $TFE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello world!", "voice": "aria", "format": "mp3"}' \
  -o hello.mp3

Clone a voice you have permission to use:

curl https://API_HOST/v1/voices/clone \
  -H "Authorization: Bearer $TFE_KEY" \
  -F file=@my_voice.wav -F name="My voice" -F consent=yes

Rules

Only clone a voice with the speaker's clear permission. Never use it to trick or harm people. Keys that break this are shut off.

Speech model: Kyutai Pocket TTS. House voices are built from LibriTTS-R (CC BY 4.0) recordings. Code: github.com/Thinkelution/TheFreeEngine.
